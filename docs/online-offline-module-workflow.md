# 线上开发与线下验收流程

## 分工

- 矫利渝：模块基础驱动、测试入口、接口初稿和集成约束。
- 占蓝雪：代码审查、边界条件、超时、安全停机、验收标准和缺陷闭环。
- 文超平：实物识别、线下接线、通电测试、数据记录、照片编号和最终硬件结论。

## 每个模块的完成定义

线上完成不等于模块通过。线上提交只能到达 `code_ready` 或 `wiring_reviewed`；模块必须满足以下全部条件才能成为 `passed`：

1. 实物型号、供电、接口和逻辑电平已记录；
2. 接线与接口冻结表一致；
3. 测试代码带超时和安全停机；
4. 文超平填写实际数据，不只写“正常”；
5. 占蓝雪复核失败路径和复测结论；
6. 结果记录包含 Git 提交号。

## 每日节奏

- 10:00 前：线上确定当天模块和接口问题；
- 18:00 前：矫利渝提交代码，占蓝雪完成第一轮审查；
- 21:00 前：文超平完成线下接线与首轮测试；
- 22:00：三人同步失败分类、修复负责人和次日复测项。
