# 八路灰度循迹模块说明

本文对应 `empty` CCS 工程中的八路灰度采集、标定、识别和差速控制代码。
循迹算法位于 `eight_gray_tracker.c/.h`，硬件采集与串口命令位于
`empty.c`。当前代码默认搭配 74HC4051 模拟多路复用器和 DRV8701
双路电机驱动。

## 1. 接线

| 八路灰度/74HC4051 信号 | MSPM0G3507 引脚 | 用途 |
| --- | --- | --- |
| A0 / S0 | PA12 | 通道地址最低位 |
| A1 / S1 | PB16 | 通道地址中间位 |
| A2 / S2 | PB17 | 通道地址最高位 |
| OUT / SIG | PA27 | ADC0 MEM0 模拟输入 |
| VCC | 按模块规格连接 | 模块供电 |
| GND | GND | 与主控、电机驱动共地 |

注意：

- 代码按地址 `0..7` 依次扫描，逻辑上规定传感器 `0` 在车体最左侧，
  传感器 `7` 在最右侧。首次测试必须移动黑线确认实际顺序。
- PA27 的输入电压不得超过 MSPM0 ADC 引脚允许范围。若灰度模块以
  5 V 供电且模拟输出可能达到 5 V，必须先按模块资料确认输出幅度，
  必要时加分压或电平调理，不能直接试接。
- 电机电源、逻辑电源和传感器地必须共地，电机电源附近应有足够的
  去耦，传感器线尽量远离电机线。

## 2. 采集时序

- 选择一个 4051 通道后等待 `8 us`。
- 每个通道连续读取 4 次 ADC 并取平均。
- 每 `10 ms` 完成一次八路采集和控制计算，即控制频率约 100 Hz。
- 串口数据默认每 `200 ms` 输出一次，避免打印阻塞控制循环。

这些参数位于 `empty.c` 顶部的 `GRAY_*` 宏中。若现场 ADC 波动明显，
优先检查供电、接地、线缆和机械高度，再考虑增加平均次数。

## 3. 上电标定流程

代码不会使用一组固定 ADC 阈值，而是为八个通道分别标定。推荐按下列
顺序操作：

1. 架起车轮或断开电机动力，复位主控。
2. 把全部探头放在白色背景上，在串口发送 `W`。
3. 把全部探头放在黑线或同材质黑色区域上，发送 `B`。
4. 发送 `T`，观察 `CAL=OK`、`CAL_BAD=0x00`。
5. 手动横向移动黑线，检查 `STATE` 是否依次为
   `LEFT -> CENTER -> RIGHT`，同时检查 `ERR` 符号。
6. 发送 `ARM` 后用低速手动命令验证电机方向；确认后才发送 `AUTO`。
7. 任何异常立即发送单字符 `X`，无需等待回车即可刹车并撤销使能。

`W` 和 `B` 各自对 8 帧采样求平均。每个通道的黑白 ADC 差必须至少
达到 80；否则该位会出现在 `CAL_BAD` 掩码中，并禁止自动行驶。例如
`CAL_BAD=0x04` 表示第 2 路（从 0 开始编号）标定跨度不足。

## 4. 识别方法

每路 ADC 值根据各自的白色值和黑色值归一化到 `0..1000`：

- `0` 表示接近白色背景；
- `1000` 表示接近黑线；
- 代码自动兼容“黑色 ADC 更低”和“黑色 ADC 更高”两种极性。

归一化值不低于 220 的通道在 `MASK` 中置位。所有通道归一化值之和
低于 500，或没有任何通道置位时，判定为丢线。

八路位置权重从左到右为：

`-3500, -2500, -1500, -500, 500, 1500, 2500, 3500`

`ERR` 是按归一化强度加权的线位置：

- 负数：线在左侧；
- 接近 0：线在中间；
- 正数：线在右侧。

当至少 6 路同时检测到黑色时，状态记为 `INTERSECTION`，当前策略是
保持基础速度直行。此策略适合先验证基础循迹；遇到正式赛题的十字、
岔路和元素识别后，应在上层状态机中单独处理。

## 5. 差速控制与丢线保护

自动模式使用 PD 控制：

`correction = Kp * ERR / 3500 + Kd * (ERR - previousERR) / 3500`

默认参数：

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `baseCommand` | 280 | 直线基础指令 |
| `maximumCommand` | 600 | 单侧最大指令 |
| `proportionalGain` | 220 | 位置偏差修正强度 |
| `derivativeGain` | 70 | 抑制快速摆动 |
| `lostSearchFastCommand` | 220 | 丢线搜索外侧轮 |
| `lostSearchSlowCommand` | 80 | 丢线搜索内侧轮 |
| `lostSearchFrames` | 15 | 最多搜索 15 个控制周期，即约 150 ms |

丢线时，车辆会根据最后一次可见位置向对应方向低速搜索。150 ms 内
仍未找回黑线则双电机刹车。复位后默认刹车，只有 `ARM` 或 `AUTO`
可以允许电机动作；手动模式还带 1 秒命令超时保护。

参数集中在 `EightGray_init()` 中。现场调参建议顺序：

1. 先把 `baseCommand` 调到车辆能稳定直行的最低速度。
2. 增大 `proportionalGain`，直到能跟线但尚未剧烈蛇形。
3. 再逐步增大 `derivativeGain`，减小摆动和过冲。
4. 最后根据弯道调整基础速度和最大指令。

一次只改一个参数，并记录赛道、速度和现象。

## 6. 串口观测字段

发送 `T` 查看状态，发送 `C` 输出归一化数据，发送 `R` 输出原始 ADC
数据，发送 `S` 停止周期数据流。

| 字段 | 含义 |
| --- | --- |
| `RAW` | 八路 ADC 原始平均值 |
| `ACT` | 八路黑线活跃度，范围 `0..1000` |
| `MASK` | 八路二值识别掩码 |
| `COUNT` | 当前检测到黑色的通道数 |
| `SUM` | 八路活跃度总和 |
| `ERR` | 加权线位置 |
| `STATE` | `UNCALIBRATED/LOST/LEFT/CENTER/RIGHT/INTERSECTION` |
| `CAL` | 标定是否有效 |
| `CAL_BAD` | 标定跨度不足的通道位掩码 |

## 7. 首次上车验收

以下项目全部通过后再提高速度：

- 八路原始值均会随黑白背景明显变化，无固定 0 或 4095 饱和通道。
- `W`、`B` 后为 `CAL=OK` 且 `CAL_BAD=0x00`。
- 黑线从左移到右时，`MASK` 位序与实际探头顺序一致。
- 黑线在左时 `ERR < 0`，在右时 `ERR > 0`。
- `LEFT` 状态下左轮命令小于右轮命令；`RIGHT` 状态相反。
- 黑线居中时两轮基本同速。
- 抬起车辆或移除黑线后，最多搜索约 150 ms，随后可靠刹车。
- 发送 `X` 后电机立即停止，复位后电机不会自行启动。

如果左右误差符号与车辆实际响应相反，先核对探头 `0..7` 的物理顺序。
应修正通道顺序或权重方向，不要同时随意交换电机方向和传感器定义，
否则后续调试很难定位问题。
