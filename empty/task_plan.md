# 任务规划：MSPM0G3507 智能运球小车

## 总目标
先把“灰度传感器可稳定读数”这条主链路跑通，再做蓝牙/串口无线调试和基础寻迹，最后再接电机闭环、陀螺仪和驱动迁移。

## 当前约束
- 调试优先走蓝牙/串口，无线看数据，不把 J-Link 作为日常调试主入口。
- 先不用电机和 12V 电池，先保证 MCU、灰度模块、供电和共地安全。
- 灰度模块需要 5V 供电，MCU 仍然是 3.3V。
- 传感器输出到 MCU 前要确认电平兼容，避免 5V 直灌。
- 现阶段重点是灰度传感器校准，不先做 PID。

## 已知资源
- 主控：MSPM0G3507
- 底板：S28A + TB6612FNG
- 传感器：感为科技 8 路灰度模块，74HC4051 复用
- 后续驱动：DRV8701
- 后续姿态：HWT101
- 显示：已装 OLED
- 调试：串口/蓝牙优先，J-Link 仅保留为必要时的烧录/恢复手段

## 任务阶梯

### 阶段 1：灰度传感器基础读数
目标：
- 读到 8 路灰度原始值
- 建立白底/黑线基线
- 验证 4051 选通和 OUT 采样是否正确

输出：
- 串口/蓝牙打印 8 路原始值
- 记录白底、黑线、半压线三种数据
- 确认传感器安装高度和离地距离

验收：
- 原始值稳定，不乱跳
- 黑白差异明显
- 丢线时能明确识别

### 阶段 2：无线调试链路
目标：
- 用 UART 或蓝牙把传感器数据发出来
- 支持最小命令或状态输出

输出：
- 读取模式、校准模式、日志模式
- 能远程看 8 路数据

验收：
- 不依赖 J-Link 也能看见传感器数据
- 手机或串口助手可直接观察

### 阶段 3：基础寻迹逻辑
目标：
- 根据 8 路数据算中心偏差
- 完成黑线检测、居中和丢线处理

输出：
- 线中心位置
- 左右偏差
- 丢线搜索策略

验收：
- 小车不接电机时，逻辑能稳定输出状态
- 纸上模拟或实车静态移动时，偏差方向正确

### 阶段 4：TB6612 低风险联机
目标：
- 只接低风险电机控制
- 先做开环最小转速验证

输出：
- 前进、后退、左转、右转
- 小幅度 PWM 调节

验收：
- 轮子悬空可控
- 不出现异常发热、掉电或重启

### 阶段 5：控制升级
目标：
- 再考虑 P / PD / PID
- 再加入 HWT101 做姿态辅助

输出：
- 稳定循迹参数
- 转弯和直线分段控制

验收：
- 跑圈稳定
- 参数可复现

### 阶段 6：整车整合
目标：
- OLED、按键、状态机、驱动迁移到 DRV8701

输出：
- 可交付版本
- 便于比赛现场调试和复位

## 本轮重点
1. 确认灰度模块 5V 供电方式
2. 确认 GND 与 MCU、蓝牙、供电侧共地
3. 先做 UART/蓝牙日志，不上电机
4. 先把 8 路原始值稳定读出来

## 未知项
- 蓝牙模块型号与串口参数
- 灰度模块输出电平是否需要分压
- 4051 的最终选通引脚与实际板卡一致性
- OLED 的总线和引脚占用
- HWT101 接口和波特率
- DRV8701 的最终替换时序和接口
