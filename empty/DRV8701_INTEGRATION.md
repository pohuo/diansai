# DRV8701 双路驱动接入说明

## 目标

本工程已从 TB6612 的双方向输入改为 LQ-DRV8701E 的 `PH + EN(PWM)` 控制：

- PWM：20 kHz，TIMG6 双通道
- 命令范围：`-1000..1000`
- 正数：前进；负数：后退；0：制动
- 上电默认：`DISARMED`，两路 EN 为 0
- 自动循迹：未完成黑白校准或检测到丢线时立即制动

## S28A H12 接线

| LQ-DRV8701 信号 | S28A H12 | MSPM0G3507 | SysConfig 名称 |
| --- | --- | --- | --- |
| 左路 EN / PWM | PB2 | TIMG6_C0 | LEFT_EN |
| 左路 PH / DIR | PA14 | GPIO 输出 | LEFT_PH |
| 控制侧电源 | 5V | 5V | - |
| 右路 PH / DIR | PA16 | GPIO 输出 | RIGHT_PH |
| 右路 EN / PWM | PB3 | TIMG6_C1 | RIGHT_EN |
| 控制侧地 | GND | GND | - |

PA13、PA17 已释放，当前驱动代码不使用。电池主电源和电机输出直接连接 DRV8701 功率端，不经过 S28A 的 AO1/AO2/BO1/BO2 细走线。

## 串口命令

所有普通命令用回车或换行结束；`X` 是唯一可以不带回车立即生效的命令。

| 命令 | 作用 |
| --- | --- |
| `ARM` | 进入手动待命，电机仍制动 |
| `M 200 200` | 左右轮各 20% 正转；必须先 ARM |
| `M -200 -200` | 左右轮各 20% 反转 |
| `M 200 -200` | 原地旋转测试 |
| `AUTO` 或 `GO` | 启动灰度 P 控制；必须先完成 W/B 校准 |
| `X` / `STOP` / `ESTOP` | 立即制动并解除使能 |
| `T` | 输出校准、循迹和电机状态 |

手动模式有 1000 ms 看门狗。若没有继续收到 `M` 命令，两路自动回到制动，但仍保持 MANUAL 状态；继续发送 M 即可恢复。自动模式丢线不会搜索，当前策略是制动等待，优先保证首次联调安全。

## 首次架空测试顺序

1. 车轮架空，先不执行 `AUTO`。
2. 上电后确认日志显示 `POWER_ON_DISARMED`。
3. 发送 `ARM`，再连续发送 `M 150 150`，确认两轮低速转动。
4. 如果某侧正命令反转，只修改 `drv8701.h` 中对应的 `*_FORWARD_PH_HIGH`，或者只对调该侧电机线，不能两处同时改。
5. 依次测试 `M -150 -150`、`M 150 -150`。
6. 执行白底 `W` 和黑线 `B` 校准，静态移动灰度板确认 ERR 左负右正。
7. 最后把车放地面，以 `AUTO` 开始低速循迹。

## 安全语义

DRV8701E 的 EN=0 是制动/慢衰减，不是 TB6612 STBY 的高阻停机。本转接接口没有使用 nSLEEP，因此软件中的 `brake` 不等于滑行。如果实际 LQ 模块另有 nSLEEP/使能端，应确认模块原理图后再扩展真正的高阻急停。
