# 视觉 UART 基础协议 v1

本协议用于 MaixCAM Pro 与 MSPM0 的基础联调，与远端 PR #2 的测试脚本兼容。

帧格式：

    $V,seq,valid,x,y,checksum*\n

字段定义：

- seq：0–255 循环递增。
- valid：0 或 1。
- x：0–319；y：0–239。
- valid 为 0 时，x 和 y 必须均为 0。
- checksum：字符串 V,seq,valid,x,y 的 ASCII 字节和对 255 取模。
- 换行可用 LF 或 CRLF；接收端忽略 CR。
- 单帧最长 47 个有效字符，超过长度立即丢弃。

接收规则：

- 连续 100 个格式、范围、校验和序号正确的帧后，代码层测试通过。
- 任何错帧或序号不连续都会把连续正确计数清零。
- 200 ms 未收到正确帧时清除旧目标并调用安全回调。
- 中断只把字节放入环形缓冲区，禁止在中断中解析字符串或控制电机。
