# 02 按键与急停测试

目标：验证模式按键、消抖、软件急停输入以及硬件断电急停。

## 接线

- 按键 GPIO、上下拉方式和有效电平均待接口冻结表确认；
- 软件急停 GPIO 只能作为状态输入，不能替代切断电机电源的硬件急停；
- 所有外部输入必须保持 3.3V 逻辑。

## 验收

- 每个按键连续操作 20 次无重复触发；
- 运行中触发急停后，PWM 立即归零；
- 硬件急停可独立切断电机输出；
- 复位后必须经过明确启动操作，不能自行恢复运动。
## 代码接口

- button_estop_interface.h：绑定毫秒计时、模式按键、软件急停输入和强制安全停机；
- test_button_estop.c：20 ms 消抖，统计 20 次独立按下，并要求至少实际触发一次急停；
- 接口回调必须非阻塞，具体 GPIO、上下拉和有效电平在 SysConfig 中冻结后实现。
