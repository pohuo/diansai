# 05 四路循迹传感器测试

目标：确认四路输出类型、电平、黑白响应和安装高度，为基础循迹提供稳定输入。

## 接线

- 先确认模块输出为数字量还是模拟量，不按商品标题猜测；
- 逐路测量黑/白表面输出电压；
- 任何 5V 输出不得直接进入 MSPM0 GPIO/ADC；
- 四路信号编号必须与小车从左到右的位置一致。

## 验收

- 四路均能区分黑白，保存原始值；
- 开机执行一次阈值或黑白标定；
- 断线或全丢线时进入停止/重找状态；
- 连续读取 10 分钟无卡死。
## 代码接口

- line_sensor_interface.h：固定通道 0 到 3 为车体从左到右，支持数字量或 ADC 原始值；
- 先分别调用 LineSensorTest_CaptureSurface(BLACK/WHITE) 采集黑白样本；
- 检测代码自动计算每路中点阈值与黑白极性，四路对比度均达标后通过；
- 数字模块最小对比度可设为 1，模拟模块应根据噪声实测提高。
