# 08 二维云台测试

负责人：矫利渝（状态机、接口定义、验收标准）；文超平（驱动器接线、限位检查、低速实测）。

## 已交付

- gimbal_interface.h：抽象使能、目标角度、到位反馈、限位和急停，兼容步进或舵机板级实现。
- test_gimbal.c/.h：必须人工 Arm 的小角度状态机、目标超时、软硬限位检查、急停和安全失能。
- result-template.md：十轮重复验收记录。

## 默认安全动作

每轮依次执行：水平 +15° → 0° → -15° → 0° → 俯仰 +10° → 0° → -10° → 0°。完成 10 轮后自动失能。任何急停、限位、命令拒绝或单目标超过 2 秒未到位都会立即失能并失败。

## 接入步骤

1. 确认云台是 STEP/DIR/EN 步进驱动还是 PWM 舵机，再实现 GimbalInterface；当前不冻结 GPIO，避免猜错驱动类型和引脚。
2. 电机必须通过专用驱动与合适电源供电，禁止由 MSPM0 GPIO 直接供电。
3. 上电后 Init 保持失能。确认机构无遮挡、零位正确、急停有效后，由操作者调用 Arm。
4. 主循环非阻塞地调用 RunOnce；角度闭环、脉冲发生和限位读取由板级适配层负责。

## 验收

- 上电不突转，未 Arm 时不会输出运动命令。
- 正反向、回零、限位和急停均有效。
- 十轮小角度测试无撞限位、无丢步或明显抖动。
- 完成、失败或主动 SafeStop 后驱动均进入安全失能状态。
