# 04 编码器测试

目标：确认左右编码器 A/B 相、电平、方向和每轮计数，并输出稳定测速结果。

## 接线

- A/B 相接入支持定时器捕获/QEI 的 GPIO，具体引脚填写接口冻结表；
- 接入前实测编码器高电平，超过 3.3V 时使用电平转换或合适上拉；
- 编码器地必须与 MSPM0 共地；
- 当前 2340 计数/车轮圈仅为采购规格，必须实测标定。

## 验收

- 手动正反转时计数方向正确；
- 低速无明显跳变，停止时速度归零；
- 左右轮分别标定每圈计数；
- 记录固定周期测速数据和溢出处理结果。
## 代码接口

- encoder_interface.h：绑定左右累计正交计数和毫秒计时，可选绑定安全停机；
- 每 20 ms 采样一次，分别记录左右轮正、反方向是否出现；
- 单周期计数变化超过 10000 判为异常，2340 计数/圈只作为待实测标称值。
