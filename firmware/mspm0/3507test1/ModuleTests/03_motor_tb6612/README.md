# 03 TB6612FNG 电机驱动测试

目标：完成左右电机低占空比启动、正反转、限幅和安全停机。

## 接线

| TB6612FNG | 连接要求 |
|---|---|
| VM | 经验证的电机电源，不得直接假定为 3S |
| VCC | 3.3V 逻辑电源 |
| GND | 与 MSPM0 共地 |
| STBY | 3.3V GPIO，默认保持关闭 |
| AIN/BIN、PWMA/PWMB | 具体引脚填写接口冻结表 |
| AO/BO | 接对应电机，首次测试轮胎离地 |

先确认驱动连续/峰值电流覆盖电机堵转电流。首次运行限制 PWM，并准备硬件急停。

## 验收

- 左右电机各正反转 10 次；
- PWM=0 时电机停止，方向切换前先归零；
- 记录空载电流、启动压降和驱动温升；
- 超时或急停时进入 `SafeStop`。
