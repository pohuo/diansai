# 06 STP-23L 测距测试

负责人：矫利渝（检测逻辑、接口定义、验收标准）；文超平（接线、抓取原始数据、距离实测）。

## 已确认参数

资料来源：https://cdn.robotshop.com/rbm/54696a9c-3d36-46d3-9713-0702899f1a68/0/016e7679-e434-4126-bd9f-a6dcffeb6beb/3e2d4afc_ldrobot_stp-23l_datasheet_en_v1.0.pdf

依据 STP-23L 公开数据手册：供电 4.5–5.5 V（标称 5 V），UART 逻辑电平标称 3.3 V，串口为 230400 baud、8N1、无流控，传感器以 120 Hz 单向发送，量程 30–7500 mm。RX 是生产调试接口，用户侧无需发送命令。

## 重要限制

公开数据手册没有定义数据帧字段、帧头或校验算法，因此代码没有猜测或套用其他传感器常见的 0x59 协议。tof_stp23l_interface.h 接收的是“经验证解码器输出的样本”。拿到厂家协议或抓取并确认原始帧后，再单独补充 UART 解码适配层。

## 已交付

- tof_stp23l_interface.h：已解码样本、非阻塞轮询、毫秒时钟与超时安全回调。
- test_tof_stp23l.c/.h：量程检查、参考距离误差、连续样本、统计和拔线超时检测。
- result-template.md：线下验收与原始数据记录。

## 验收

1. 先用逻辑分析仪或 USB-TTL 保存至少 5 秒原始字节流，标记静止距离和串口参数。
2. 用卷尺设置已知距离，通过 SetReference 输入参考值和允许误差。
3. 连续 120 个有效样本均在误差内后通过。
4. 拔掉传感器，100 ms 后必须进入超时失败并触发一次安全回调；主循环不得阻塞。
5. 距离小于 30 mm 或大于 7500 mm 时按超量程处理。
