# MSPM0 单模块主机回归测试

本目录在电脑上模拟硬件回调，覆盖 01–08 模块的正常、故障与安全停止路径，不参与 CCS 目标固件构建。00 板级启动依赖 DriverLib、SysConfig 生成文件和目标寄存器，由 TI Arm 编译链与实物心跳测试覆盖。

## 覆盖范围

| 模块 | 正常路径 | 故障/安全路径 |
| --- | --- | --- |
| 01 电源监测 | 32 次采样与 3% 标定 | 低压去抖、锁存回调 |
| 02 按键急停 | 20 次消抖按键 | 急停强制安全输出 |
| 03 TB6612 | 十轮低占空比正反转 | 急停、失能、零占空比 |
| 04 编码器 | 左右轮正反方向 | 单周期异常跳变 |
| 05 循迹 | 黑白四路标定与掩码 | 低对比度失败 |
| 06 STP-23L | 120 个参考距离样本 | 拔线超时 |
| 07 视觉 UART | 100 个协议帧 | 200 ms 失联超时 |
| 08 云台 | 十轮小角度状态机 | 急停立即失能 |

## 运行

PowerShell 中执行：

    .\run.ps1

若 gcc 不在 PATH，可指定：

    .\run.ps1 -Gcc "D:\computer programming\mingw\mingw64\bin\gcc.exe"

脚本使用 C11、Wall、Wextra、Werror；任一断言或编译警告都会返回非零退出码。
